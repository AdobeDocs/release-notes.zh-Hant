# [!DNL Adobe System Status] 發行說明 {#status-release-notes}

[!DNL Adobe System Status] 提供有關 Adobe 產品和服務的詳細資訊、狀態更新和電子郵件通知。 收到有關服務中斷、作業中斷和維護事件的通知。 請前往 [status.adobe.com](https://status.adobe.com/zh-tw/){target="_blank"} 了解詳情。

此頁面會追蹤[!DNL Adobe System Status]個更新在一段時間內的變化。 只有在有新版本可報告時才會更新。

| 日期 | 更新 |
| ------- | ------- |
| 2026年3月 | <ul><li>AI 虛擬助理 Beta 版</li><li>錯誤修正與改善功能</li></ul> |
| 2025年12月8日 | <ul><li>虛擬助理意見反應增強功能（簡化的引導式工作流程、直覺式圖示）</li><li>錯誤修正與改善功能</li></ul> |
| 2025年7月16日 | <ul><li>正式推出虛擬助理</li><li>在Product和Cloud頁面上以及虛擬助理中搜尋事件ID</li><li>Slack 通知設定更新</li><li>錯誤修正與改善功能</li></ul> |
| 2025年3月20日 | <ul><li>虛擬助理 Beta 版</li><li>新增事件字彙表說明頁面</li><li>錯誤修正與改善功能</li></ul> |
| 2024年8月19日 | <ul><li>產品型維護通知（增強的UI和每個產品的通知）</li><li>錯誤修正與改善功能</li></ul> |
| 2024年4月11日 | <ul><li>用於設定主動通知設定檔和偏好設定的訂閱說明頁面</li><li>通知改善（透過電子郵件和Slack的CSO關閉通知）</li><li>錯誤修正</li></ul> |
| 2024年1月30日 | <ul><li>公告現在是狀態API的一部分</li><li>介面效能改良</li></ul> |
| 2023 年 10 月 | <ul><li>新的「說明」功能表，包含「概觀/首頁」的導覽</li><li>Status API檔案已更新至OAuth 2.0</li><li>錯誤修正（雲端頁面橫幅、已關閉事件電子郵件、重複事件、訂閱可靠性）</li></ul> |
| 2023年7月18日 | <ul><li>公告：全域、雲端或產品層級訊息具有廣泛影響，現在可做為訂閱選項使用</li><li>效能和訂閱增強功能</li><li>通知錯誤修正</li></ul> |
| 2023 年 3 月 | <ul><li>沒有新的更新；請參閱2023年1月以瞭解最新功能（狀態API）</li></ul> |
| 2023年1月19日 | <ul><li>現在可透過Adobe Status Slack應用程式在Slack上取得狀態通知</li></ul> |
